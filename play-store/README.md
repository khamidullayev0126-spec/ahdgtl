## 3. Yopiq test (Closed testing) — 12 testchi, 14 kun

Yangi shaxsiy akkauntlar uchun Google talabi: ilova hammaga chiqishidan oldin **kamida 12 kishi 14 kun davomida** ilovani o'rnatib turishi kerak.

1. Play Console → Testing → **Closed testing** → Create track.
2. Testers → **Email list** → 12+ ta Gmail manzil.
3. Ularga «Join on the web» havolasini yuboring — har biri havolani ochib, «Become a tester» ni bosadi va ilovani Play Market'dan o'rnatadi.
4. 14 kun davomida ilovani o'chirib yubormasliklari kerak.
5. 14 kundan keyin: **Apply for production** → Google ~7 kun ichida tekshiradi.

Testchilarga yuboriladigan xabar:
```
Salom! Mening AHdigital ilovamni Google Play'da test qilishga yordam berasizmi? 
1) Shu havolani oching va «Become a tester» ni bosing: [HAVOLA]
2) Play Market'dan ilovani o'rnating.
3) 14 kun o'chirmay turing — bir-ikki marta ochib ko'rsangiz kifoya.
Rahmat! 🙏
```

## 4. Ilova faylini yasash (pul to'langandan keyin)

1. https://www.pwabuilder.com → `https://www.ah-digital.uz/app.html` → Start.
2. **Package for stores → Android → Google Play**.
3. Sozlamalar:
   - Package ID: `uz.ahdigital.app` (keyin o'zgartirib bo'lmaydi!)
   - App name: `AHdigital`, Launcher name: `AHdigital`
   - Version: `1.0.0`, version code: `1`
   - Signing key: **Create new** — yuklab olingan ZIP'dagi `signing.keystore` va parollarni **xavfsiz joyda saqlang** (yo'qolsa, ilovani yangilab bo'lmaydi). Parollarni chatga yozmang.
4. ZIP ichidagi `assetlinks.json` dan **SHA-256 fingerprint** ni oling (bu maxfiy emas).
5. Render → Environment: `ANDROID_PACKAGE=uz.ahdigital.app`, `ANDROID_SHA256=<fingerprint>`.
   Play App Signing yoqilgach, Play Console → Setup → App signing'dagi **Google'ning SHA-256** ini ham vergul bilan qo'shing.
6. `.aab` faylni Closed testing'ga yuklang.
