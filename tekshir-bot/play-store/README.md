## 3. Ilova faylini yasash (PWABuilder)
1. **pwabuilder.com** → manzil: `https://tekshir.ah-digital.uz` → **Start**.
2. **Package for stores → Android → Generate package**:
   - Package ID: `uz.ahdigital.tekshir`
   - App name: `Tekshir`, Launcher name: `Tekshir`
   - Theme/background color: `#0a1020`
   - Signing key: **Create new** — yuklab olingan **signing key fayli va parollarini xavfsiz saqlang** (yo'qolsa, ilovani yangilab bo'lmaydi). GitHub'ga YUKLAMANG.
3. Yuklab olingan arxivdagi `assetlinks.json` ichidan **SHA-256** ni oling.
4. Render → bot xizmati → Environment:
   - `ANDROID_PACKAGE` = `uz.ahdigital.tekshir`
   - `ANDROID_SHA256` = (o'sha SHA-256)
   Tekshirish: `https://tekshir.ah-digital.uz/.well-known/assetlinks.json` ochilishi kerak.
5. Play Console → yangi ilova → `.aab` faylini **Closed testing** ga yuklang.
