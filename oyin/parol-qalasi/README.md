# 🏰🏹 Parol qal'asi

O'yin endi Tekshir bot serverida ishlaydi:

- **O'yin:** https://tekshir.ah-digital.uz/qala
- **Kod:** `tekshir-bot/qala/index.html` (sahifa) va `tekshir-bot/src/qala.js` (server)
- **Testlar:** `tekshir-bot/tests/qala.test.js`

Faylni kompyuterdan ochsangiz — faqat «Mashq» rejimi ishlaydi (onlayn o'yin uchun server kerak).

## Bosqichlar
1. ✅ Kamon o'yini: tortib otish, qalqon, shamol, bonus sharlar, vaqt, darajalar
2. ✅ Server: username (takrorlanmaydi), o'z qal'asi (8–16 belgi), boshqalarga hujum
3. ✅ Reyting jadvali, bildirishnomalar, tiklash kodi (boshqa qurilmadan kirish)
4. ⬜ Silliqlash, keyin Kotlin ilova
